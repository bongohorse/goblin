# Domain Notes

Beat your Goblin is a small single-context game repository.

Important vocabulary:
- Goblin / ragdoll
- body parts, rigid bodies and joints
- tools and thrown objects
- score, combo and round goals
- arena, camera and presentation
- pointer/touch input
- CI build and GitHub Pages deployment

Do not invent new architecture terminology for a small change. Add a glossary or ADR only when a decision must remain stable across future work.
