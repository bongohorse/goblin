## Upright and damping contract
SI; quaternion xyzw active local-to-world. Torso local up (0,1,0); world target Y-up. u=normalize(R(q)*up), c=u cross Y, theta=atan2(|c|,u dot Y); world rotation error e=theta*c/|c|. Normalize quaternion, q and -q equivalent. theta near zero -> e=0. Antiparallel or theta>.2 rad -> explicit invalid/outside-domain, no arbitrary axis or continuation. This is a bounded small-tilt controller, not global get-up. World yaw is not targeted. omegaT and omegaP are world rad/s; log both and relative omegaT-omegaP. Damping uses transverse WORLD torso speed omegaTilt=omegaT-u*(omegaT dot u), not relative speed. tauRaw=Kp*e-Kd*omegaTilt. Spin about torso up remains uncommanded; torque dot u=0. A co-rotating pair can therefore receive damping even with zero relative speed. The arm receives exactly -tau in the same WORLD frame: angular momentum is exchanged internally; world-referenced damping is dissipative for torso tilt but is not guaranteed dissipative for total two-body energy (power=tau dot (omegaT-omegaP)). No free external support. Euclidean vector cap |tau|<=.15 Nm, not a per-axis box. Off resets to zero; wrong-sign changes proportional sign only; missing-reaction deliberately adds external net torque and is never accepted.
